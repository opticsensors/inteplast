# Ontologia d’Inteplast

Primera proposta visual dels conceptes i les relacions de la solució, preparada
el 28/09/2026 a partir de la documentació i del codi existent.

- `index.html`: diagrama SVG dins d’un HTML autònom, sense dependències ni connexió
  a Internet. Obrir-lo al navegador; també té estil d’impressió horitzontal.
- `ontology.png`: imatge del mateix esquema per inserir-la en un correu o document.

És un esquema inicial per revisar amb enginyeria, no una ontologia OWL executable
ni un diagrama de totes les taules de la base de dades. Les medicions i correccions
poden estar representades en dades importades estructurades. La interpretació de
correccions està desenvolupada per al pilot 3212. Les categories es consideren
editables segons l’abast previst indicat per Eduard.

Les fletxes expressen relacions entre conceptes, no una seqüència d’execució ni
cardinalitats. Una proposta de correcció no implica execució confirmada ni una
millora demostrada. Les notes d’advertiments i lliçons les aporten els usuaris.

Fonts: `docs/modelo-datos.md`, `docs/cotas-y-evidencia-web.md`,
`backend/app/models.py`, `backend/app/knowledge_models.py` i
`backend/app/measurement_models.py`.
